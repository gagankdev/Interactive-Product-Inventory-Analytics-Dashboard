JavaScript Internship Assignment & Mini Project

📌 Overview

This repository contains JavaScript practical assignments and a capstone mini project completed as part of my internship learning tasks. The assignments focus on fundamental JavaScript concepts, while the final project combines these concepts into a Product Inventory & Analytics System.

🎯 Objectives

- Understand JavaScript fundamentals and syntax.
- Practice variables, data types, operators, and conditional statements.
- Learn loops, functions, and scope.
- Work with arrays, objects, and built-in array methods.
- Apply JavaScript concepts to a practical mini project.

📚 Assignments

Assignment 1: Variables, Data Types & Console Operations

- Declare variables using "var", "let", and "const".
- Check data types using "typeof".
- Display user information and skills in the console.

Assignment 2: Operators, Expressions & Input Handling

- Take bill amount and tip percentage using "prompt()".
- Convert inputs using "Number()".
- Calculate the tip and total bill amount.

Assignment 3: Conditional Logic

- Implement "if...else" statements.
- Assign letter grades using conditional logic and "switch".
- Determine pass/fail status using the ternary operator.

Assignment 4: Loop Control Structures

- Generate a multiplication table using a "for" loop.
- Find a number using a "while" loop and "break".
- Demonstrate "do...while" and "continue".

Assignment 5: Functions & Scope

- Create standard and arrow functions.
- Calculate the area of a rectangle.
- Demonstrate default parameters and block scope.

Assignment 6: Arrays, Objects & Core Methods

- Store product details in an array of objects.
- Display products using "forEach()".
- Filter products using "filter()".
- Generate formatted product information using "map()".

🚀 Capstone Mini Project: Product Inventory & Analytics Dashboard

Project Description

The Product Inventory & Analytics Dashboard is a JavaScript-based console application that manages product information and generates basic inventory analytics.

Key Features

- Add a new product using user input.
- Validate product name and price.
- Categorize products as Budget, Standard, or Premium.
- Display the inventory using "forEach()".
- Calculate the total inventory value.
- Filter affordable products priced under $200.
- Generate a formatted product report using "map()".

Technologies Used

- HTML5
- JavaScript
- Browser Console
- JavaScript Array Methods

Sample Output

When a Monitor priced at $150 is added to the initial inventory:

- Laptop — $800 — Premium
- Mouse — $25 — Budget
- Monitor — $150 — Standard

Total Inventory Value: $975
